# Vendored fonts (OFL — SIL Open Font License 1.1)

The HUD uses three open-licensed display faces, downloaded as WOFF2
(latin subset) from Google Fonts and vendored here so the game makes
zero network requests. All three are licensed under the SIL Open Font
License 1.1, which permits embedding in a game.

- **Passion One Bold** (`passion-one-bold.woff2`) — display face for
  money, WASTED/BUSTED, mission titles and popups. The closest OFL
  match to the tall condensed density of GTA's display type.
  Designer: Jack Olaf Nielsen. Source: google/fonts `ofl/passionone`.
- **Barlow Condensed SemiBold** (`barlow-condensed-semibold.woff2`) —
  HUD text: objectives, subtitles, ammo numbers. Designer: Jeremy
  Tribby. Source: google/fonts `ofl/barlowcondensed`.
- **Yellowtail** (`yellowtail.woff2`) — vehicle/location script face,
  the Sign Painter role. Designer: Astigmatic (Brian J. Bonislawsky).
  Source: google/fonts `ofl/yellowtail`.

Deliberately NOT used: **Pricedown** (the GTA wordmark face) — its free
licence covers desktop/static artwork only; embedding it in a game or
website is not covered. Passion One is the OFL stand-in.
